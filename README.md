# Zsh Full Installer Script

This script installs Zsh along with Oh My Zsh and popular plugins in a single step. It also updates your `.zshrc` configuration and sets Zsh as your default shell.

##  Features

- Installs Zsh and required dependencies
- Installs [Oh My Zsh](https://ohmyz.sh/)
- Adds popular plugins:
  - `zsh-autosuggestions`
  - `zsh-syntax-highlighting`
  - `zsh-completions`
- Configures `.zshrc` with plugins and sources them
- Sets Zsh as your default shell
